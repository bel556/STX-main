# 🚗 STX — Driving School Discovery & Booking Platform

**STX** is a simple and modern web platform that allows users to **discover, compare, and book** nearby **driving schools (auto-écoles)**.  
It helps learners find the best options around them, while giving driving schools a space to promote their offers and connect directly with potential students.

---

## 🌟 Features

### 👨‍🎓 For Students
- Search and browse nearby driving schools.
- Compare prices, ratings, and offers.
- View detailed school profiles (description, contact info, offers).
- Book appointments or driving lessons online.

### 🏫 For Driving Schools
- Register and create a school profile.
- Add and manage offers, courses, and pricing.
- Receive booking requests from learners.
- Upload materials like eBooks or videos (optional future feature).

---
## ⚙️ Tech Stack

**Frontend:**
- HTML5  
- CSS3 (custom styling, no frameworks)
- JavaScript (Vanilla JS)
- Fetch API for backend communication

**Backend:**
- Node.js + Express.js
- MongoDB (with Mongoose)
- JWT for authentication
- dotenv for configuration
